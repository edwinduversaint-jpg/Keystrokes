# Keystroke

A typing speed test that runs entirely in the browser — no build step, no server.

## Features
- Timed tests: 15, 30 or 60 seconds (the clock starts on your first keystroke)
- Live words per minute and accuracy while you type
- Results chart of WPM over the test, with errors marked
- Common-words and hard mode (longer words, capitals, punctuation, numbers)
- 8 languages — English, Español, Français, Deutsch, Italiano, Português, Nederlands, Русский — switching changes both the practice words and the whole interface
- Personal bests and recent results saved in your browser (localStorage)
- FAQ, light and dark themes, works on phones

## Run it
Open `index.html` in any modern browser.

## Keyboard shortcuts
- `Tab` or `Esc` — restart
- `Enter` — next test from the results screen
